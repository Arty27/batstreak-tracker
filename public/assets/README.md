# Image placeholders

Drop personal Batman-themed images here, then wire them into `src/main.tsx` or `src/styles.css`.

Good candidates:

- `bat-symbol.png` for the hero placeholder panel.
- `gotham-skyline.jpg` for a stronger page background.
- `favicon.svg` or `favicon.png` for the browser tab icon.

Keep any downloaded artwork for personal use only unless you have rights to use it elsewhere.
